Settings

Every setting, its default and what it changes.

Name Default What it does
retries 3 How many times a failed step is tried again.
timeout 30 seconds How long a step may take before it stops.
notify Off Sends a message when a run ends.

Changing timeout

A shorter timeout ends slow steps early; they are not tried again.

Example

setting = value
another = value
