README

deploy.local

Deploy apps and run coding agents on computers you own. One coordinator, any number of workers, hosted Git and a phone app.

Develop

To work on deploy.local itself, clone it and run:

pnpm install
pnpm dev

What you get

  • Hosted Git with pull requests, issues and releases
  • Agents that work on your code in tasks, on your own computers
  • Releases that prepare, verify and activate, with automatic rollback

Read AGENTS.md before changing anything people will see.
