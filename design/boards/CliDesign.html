CLI · design

A design change, from a terminal.

Anyone working outside a task had to fetch, branch, name layers, render, pair and call the API by hand. deploy design start makes the branch from main in its own folder, so it is never behind the approved design. deploy design check draws what changed beside main, in light and dark, and says what is wrong.
deploy design startAlways from main as it is now, in a folder of its own
zsh
~/deploy.local $ deploy design start "Sidebar by project"
✓ Fetched main                     518a1ea · 2 min old
✓ Branch                           design/sidebar-by-project
✓ Folder                           ../deploy.local-sidebar-by-project

Sidebar by project is yours on MacBook Pro.
It shows on the Design page as being worked on.

Edit the boards in design/boards, then:
  cd ../deploy.local-sidebar-by-project
  deploy design check
deploy design checkExit code 1 while a board has a problem
