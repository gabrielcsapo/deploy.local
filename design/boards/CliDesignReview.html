CLI · design review

Propose it, and hear back.

A design proposed from a terminal used to need the Propose button or an API call, and Ask for changes on it told nobody. deploy design propose checks, pushes and asks. deploy design feedback waits for the answer and prints the note and every pin, so the notes always reach whoever is doing the work.
deploy design proposeChecks first; nothing is proposed with a problem in it
zsh
~/deploy.local-sidebar-by-project $ deploy design propose
Title     Sidebar by project

Hear back with:
  deploy design feedback --wait
