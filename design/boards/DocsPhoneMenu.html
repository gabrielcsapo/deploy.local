Releases and rollback

A release is one version of a whole project: every app in it, plus its database migrations. You start every release, by pressing Ship or merging a pull request.

On this page

How a release runs

  • Prepare · build every app in the project
  • Verify · start the release on a copy and check that it answers
  • Activate · switch traffic and run migrations
  • Watch · Warden watches it for 10 minutes
