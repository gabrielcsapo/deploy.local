CLI · design build

Build it, then prove it.

An approved design used to be built from memory, and the check that the app matched was the builder's own word. deploy design build lists what is approved and not built, and prints the brief. deploy design verify captures the running app at the board's widths, in light and dark, and compares each capture with its board.
deploy design buildWith no name it lists what is waiting to be built
zsh
~/deploy.local $ deploy design build
Approved, not built
  push-origin          Push to origin, not deploy      3 days
  sidebar-by-project   Sidebar by project              just now

~/deploy.local $ deploy design build sidebar-by-project
✓ Yours on MacBook Pro           the Design page shows who is building
  Boards    Sidebar, Projects, Project
  Widths    1440 · 700
  Data      home-gym, tally, deploy.local
  Words     "Group tasks by", "Show archived"

Build it, then:
  deploy design verify
deploy design verifyExit code 1 while a capture differs from its board
zsh
~/deploy.local $ deploy design verify

✓ Project matches its board      0.4% apart at most
