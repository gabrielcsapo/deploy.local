Start

Install on a computer

Choose a computer that can stay on and remain connected to your home network. It will be the coordinator. Then add your other computers with the desktop app or the CLI.

Before you start

You need Docker for apps, Git for repositories, and OpenSSL for local certificates. The source checkout also needs the JavaScript runtime and pnpm versions listed in its package.json.

Set up the coordinator

Build the source checkout on your always-on computer, then run its local setup installer before starting the coordinator. Choose fresh to create the home certificate and print a single-use setup code.

git clone https://github.com/gabrielcsapo/deploy.local.git
cd deploy.local
pnpm install --frozen-lockfile
pnpm build
pnpm exec tsx server/v2/setup-installer.ts
pnpm start

Open the printed address ending in /setup and enter the code to create your first account. The code expires after 30 minutes.

Recover a home

Choose recover in the local setup installer with your recovery bundle, its passphrase and an empty replacement data folder, then open /recover to check the result.

Add your other computers

Each laptop or desktop can join as a computer that takes tasks for your agents. Use the desktop app on a computer you sit at, and the CLI on a server without a screen.

The desktop app

Apple silicon. Windows and Linux builds aren’t published yet.
  • 1Open deploy.local Desktop. It finds deploy.local on your network, or you type your coordinator’s address.
  • 2Check that the certificate it shows is your coordinator’s, then sign in.
  • 3Choose what it helps with. Take tasks is on; Use the screen asks for macOS permissions first.
  • 4Choose Add. It appears in Computers. Closing the window keeps it working; Quit stops it.
The app isn’t notarized yet, so macOS stops it the first time. Open System Settings → Privacy & Security and choose Open Anyway. You do this once.

The CLI

For a computer without a screen, or to deploy from a terminal. Run it on each computer that needs the CLI, with your coordinator’s address.

macOS and Linux
curl -fsSL http://deploy.local/install | sh
Windows PowerShell
irm http://deploy.local/install.ps1 | iex

Then run deploy login and approve the matching code in your browser. Later, deploy upgrade replaces the CLI with the build your coordinator serves.

Trust your home certificate

Download your coordinator’s CA certificate and trust it on each device you use. On macOS, add it in Keychain Access and set its trust. On iPhone, install the profile, then enable full trust in Certificate Trust Settings.

Add a passkey

Passkeys become available over HTTPS after the browser trusts the certificate. Sign-in offers a passkey first when your account has one.
