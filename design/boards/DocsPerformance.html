Performance

deploy.local counts every request to your app at its edge, so the app's Requests page always has totals. Its Performance page shows more when the app reports it: where each route spends its time, how pages feel in the browser, and errors grouped by cause. Apps built on react-flight-router report all three on their own.

Route timing

Add a Server-Timing header to each response. Name the route pattern, not the address, so /photos/12 and /photos/13 count as one route.

Server-Timing: route;desc="/photos/:id", match;dur=0.4, render;dur=38

route is required, once per response: a pattern that starts with /. match, render and action are optional times in milliseconds, and become the steps of the route's waterfall.

A route with a query or # in it is ignored, so IDs and search terms never end up in Performance.

Page experience

From the page, POST a JSON batch to /__deploy/telemetry on the app's own address when the page settles, and again when it is hidden. Times are in milliseconds; cls has no unit. Send up to 100 events in one batch.

{ "v": 1, "build": null,
  "events": [{ "type": "load", "route": "/photos/:id",
               "ttfb": 120, "fcp": 640, "lcp": 1840, "inp": 96, "cls": 0.02 }] }

Errors

From the server, POST to $DEPLOY_TELEMETRY_URL/v1/server with the token in DEPLOY_TELEMETRY_TOKEN. deploy.local sets both in your app's environment. Errors with the same fingerprint are grouped: 40 hex characters you choose, such as a SHA-1 of the error's name and first stack frame.

curl -X POST "$DEPLOY_TELEMETRY_URL/v1/server" \
  -H "Authorization: Bearer $DEPLOY_TELEMETRY_TOKEN" \
  -d '{ "v": 1, "records": [{ "t": 1763500000000, "kind": "error",
        "route": "/photos/:id", "where": "ssr", "name": "TypeError",
        "message": "photo is undefined", "stack": "…",
        "fingerprint": "3f2a9c…" }] }'

Errors in the page go in the page's batch, with "type": "error" and the same fields.

Release comparisons

Once any of these arrive, each release is compared with the traffic before it: typical and slow request times, and the error rate. The release shows as Steady, Slower or More errors.
