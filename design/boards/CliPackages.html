CLI · packages

Sign in npm once. Publish from the folder.

npm login opens deploy.local in your browser and gives npm and pnpm a publishing key. Installing needs none. pnpm publish publishes the package in the current folder under your name. Tasks never publish: their computers can install but not publish, so packages from a task are published by the pipeline when you merge.
Signing in, then setting up a projectEach step names the file it wrote
