Get started

deploy.local runs on a computer at home that stays on. These docs call it SER; yours can have any name. Setup takes about ten minutes.

1

Install on the computer that stays on

It needs Docker. The installer checks the computer, then asks one question: start fresh, or recover from a backup.

curl -fsSL https://github.com/gabrielcsapo/deploy.local/releases/latest/download/install.sh | sh
2

Finish setup in a browser

On any computer at home, open deploy.local/setup and enter the code the installer printed. You make the first account with a passkey.

3

Add your other computers

Install the desktop app on a Mac, Windows or Linux computer and it joins as a worker. Pick what it does: take tasks, run apps, serve models, or use the screen.

4

Ask for something

Type what you want on Home. A question gets an answer. A change becomes a task, then a pull request you review. Nothing ships until you press Ship.

Words you will see

ProjectA repository and the apps it runs. Releases, logs and secrets belong to it.
TaskWork an agent does on one of your computers. It ends in a pull request.
ReleaseOne version of a whole project, shipped by you, verified before it goes live.
Waiting on youDecisions only you can make. The only place a ! appears.
LiveEverything running right now, by computer.
Agents you createName an agent, then teach it in chat. Confirm Looks after items when you want it to work on its own.
